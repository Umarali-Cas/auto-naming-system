# Ударения в именах (Next.js)

    npm install
    cp .env.example .env.local   # задайте AUTH_SECRET
    npm run dev                  # http://localhost:3000

Демо-вход: demo@example.com / demo12345. Регистрации нет: свой аккаунт задаётся через ADMIN_EMAIL / ADMIN_PASSWORD в .env.local.
Ударение пишется как «+» перед ударной буквой (+Ольга). Пачка из 200 имён грузится при открытии страницы, кнопка «Обновить» запрашивает API заново.

Заглушки, которые заменяются при внедрении:
- lib/names-source.ts — откуда приходят имена
- lib/llm.ts — расстановка ударений (вызов LLM + проверка ответа)
- app/api/send/route.ts — отправка принятых имён на сервер
- lib/db.ts — хранилище пользователей (сейчас в памяти)

Вкладки: «На проверку», «Неуверенные» (уверенность модели ниже 70%, порог CONF_THRESHOLD в lib/stress.ts), «Ошибки», «История». В списках по 50 записей на страницу.
Исправленное во вкладке «Ошибки» имя уходит на заглушку отправки (/api/send) и исчезает из списка.

## LLM
Ключи и модели задаются в .env.local (см. .env.example). Для Groq: GROQ_API_KEY, модели в GROQ_MODELS (Llama 3.x на Groq выключены 16.08.2026, по умолчанию gpt-oss и qwen).
Выпадающий список «Модель» показывает всех провайдеров, для которых задан ключ, плюс заглушку без LLM. Выбор запоминается в браузере и применяется при «Обновить» и при исправлении во вкладке «Ошибки».
- lib/llm/config.ts: провайдеры и модели (свой OpenAI-совместимый API: CUSTOM_LLM_*)
- lib/llm/prompt.ts: промпт
- lib/llm/call.ts: HTTP-вызов
- lib/llm/index.ts: пачки по 30 имён, проверка ответа, повтор неудавшихся, кэш повторяющихся имён

## Несколько ключей, две модели, опечатки
- Ключи: в `*_API_KEY` можно перечислить несколько ключей через запятую. Запросы идут по кругу, а ключ с лимитом (429), без кредитов (402) или недействительный (401) пропускается и берётся следующий (lib/llm/keys.ts, lib/llm/call.ts).
- Две модели: в «Модель 1» и «Модель 2» выбираются разные LLM, пачка делится между ними порциями по 20 имён; если одна отказала, остальное обрабатывает другая.
- Опечатки: модель помечает искажённые имена (ok:false), код ищет ближайшее имя в словаре (lib/fuzzy.ts, словарь в lib/names-dict.ts) и кладёт запись в «Неуверенные» с исходным написанием и пояснением.
